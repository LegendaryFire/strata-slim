Windows build: merge of main (upstream v0.2.17) into windows-build
=====================================================================

Conflicts resolved
------------------
- README.md: kept both sections, the Windows instructions and main's new
  "Generating the settings for your machine" section.
- common.py: kept the branch's ROOT = the scripts' own folder instead of a
  hardcoded /opt/strata. In the image those are the same path, so Docker is
  unaffected, and it also works from the Windows folder.
- launch.py: kept the branch's import, which includes ON_WINDOWS.

Fix
---
- scripts/build_windows.ps1 always built strata_kq. Since v0.2.15 that target
  only exists with -DSTRATA_MMQ=ON, so the build would have failed. The script
  now checks that the target exists first, the same way the Dockerfile does.
  The staging step already skipped strata_kq.dll when it was missing.

Left out on purpose
-------------------
- configure.py is not in the Windows bundle: it reads /proc/meminfo and /sys,
  which Windows does not have.

Building
--------
Needs Visual Studio 2022 Build Tools ("Desktop development with C++"), the
CUDA 13.0 toolkit, Git for Windows and Python 3. On the Windows machine:

    git checkout windows-build
    powershell -ExecutionPolicy Bypass -File scripts\build_windows.ps1 -CudaArchitectures 86 -Patches all

CudaArchitectures: 86 = RTX 30, 89 = RTX 40, 120 = RTX 50.
The result is build\windows\strata-slim\, plus a zip of it.

If -Patches all fails to apply, try it without -Patches first to confirm the
plain build works.
