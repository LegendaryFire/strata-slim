# What strata-slim takes from upstream Strata (https://github.com/Niko1221/Strata).
#
# One git pathspec per line, relative to the upstream repo root. A trailing "/" takes the folder.
# Since v0.2.16 upstream keeps the engine in engine/, the server and tools in terminal/ and packaging in tools/packaging/;
# extract.py drops the engine/ and terminal/ prefixes (and tools/packaging/ becomes packaging/), so vendor/ keeps one
# flat tree, the layout of an installed Terminal.
# A line starting with "!" excludes. Everything not listed stays out (apps/, bench/, docs/, tests/,
# the Terminal/TUI, setup.py, SYCL, Metal, ...).
#
# After editing: ./scripts/extract.py <tag>, then docker build. A Python file that needs one left out here stops with
# Python's own ModuleNotFoundError naming it: add that path here.
